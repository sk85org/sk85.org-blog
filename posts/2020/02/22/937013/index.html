葱油メモ kiki麺を再現する

2020-02-22（土） #cooking #taiwan n年日記 0222 今日memo

台湾にはkiki麺という素晴らしいインスタントラーメンがあるのだけど、
それを自宅で再現するための研究。
KiKi食品雜貨
もちろん本物のほうが美味しいけど、kiki感は出ている。

葱油 #

ネタ元はここ https://cookpad.com/recipe/5524382

材料 #

  • 万能ネギ1束(白いところが少ないやつ)
  • サラダ油200ml
  • 醤油 300ml
  • 砂糖大さじ5

作り方 #

  1. 万能ねぎをザックリと切る
  2. サラダ油に入れる
  3. ネギがいきなり焦げないように超弱火で20~30分加熱
  4. ネギの水分が完全に抜けてカサカサしたら火を止めてネギを出す。(そのまま加熱し続けると焦げて苦くなるので)
  5. 醤油と砂糖を入れて弱火で完全に砂糖を溶かす。(醤油が沸騰しないように100度以下で入れる)
  6. 十分に冷まして瓶詰め

kiki麺再現バージョン #

材料 #

  • 徳島半田麺

作り方 #

  1. 葱油とにんにくチューブをお好みで混ぜる
  2. 半田麺は塩分が強いので多めの水で茹でる
  3. 湯で時間は表記-1分
  4. 葱油と絡める
